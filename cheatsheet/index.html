Auth Track

Current state: KellyO is at v96.11. The Cloudflare Pages auth preview is live at https://kellyo-auth-preview.pages.dev/; GitHub Pages remains a static discussion preview.

  • Newcomer flow: public visitors start on a cleaner KellyO hero, click Try a planning calculator, sample named planning moves, then closing the modal scrolls them to the 1-week trial and plan CTAs.
  • Sampler moves: current examples are tabbed as S-Corp paycheck split, PTET benefit check, and Rental loss fit; keep the public sampler limited to a few strong modules.
  • Sampler controls: each example now pairs typed numeric inputs with sliders, hides browser number spinners, and shows plain-text acronym tooltips with pronunciation keys such as P-T-E-T.
  • Cleanup pass: public header says Sign In, the sampler dropped the Editable pill, and night-mode strategy cards now have stronger contrast.
  • Direction: Google OAuth is active for real access and self-serve trials; the temporary username/password gate remains only as a reviewer fallback.
  • Verification: Provider login proves identity, then KellyO checks either KELLYO_AUTH_USERS_JSON for approved users or D1 trial records before issuing its own signed HttpOnly session cookie.
  • Roles: KellyO owns authorization with Admin, Owner, Partner, Standard, Trial, and Disabled entries.
  • Trial tracking: Google-verified trial contenders write to the kellyo-auth D1 tables users and trial_requests, with a 7-day trialEndsAt.
  • Secrets/bindings: Cloudflare now has KELLYO_SESSION_SECRET, KELLYO_AUTH_USERS_JSON, Google client ID/secret, KELLYO_CLIENTS_JSON, and the KELLYO_AUTH_DB D1 binding.
  • Callback URL: Google uses https://kellyo-auth-preview.pages.dev/api/auth/oauth/callback.
  • Parked providers: Apple is the likely second consumer-friendly provider later. Microsoft is on the back burner after account/MFA friction.
  • R2 note: no R2 needed for credential verification. Use R2 later only for private documents or files, not login.
  • Cloudflare status: Wrangler OAuth works, Pages deploys succeed, and the provider endpoint reports Google configured.
